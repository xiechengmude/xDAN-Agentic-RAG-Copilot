#### 优化方案：

```python
# 增强迭代决策逻辑
Iterative Search Decision Framework:
1. Information Completeness Check:

   - Source authority sufficient?
   - Data consistency verified?
   - Key details confirmed?

   - Which aspects need verification?
   - What follow-up queries would help?
```
