# Search Model 工作原理示例

## 背景介绍

在S3（Search-Select-Synthesize）架构中，Search Model是一个专门训练的AI代理，负责智能地控制搜索过程。它不是简单地执行一次检索，而是能够评估检索结果的质量并决定下一步行动。

## 示例：回答"什么是智信平台？"

### 第1轮搜索

**初始查询**: "什么是智信平台？它主要有哪些功能？"

**检索结果**（假设）:
```
文档1: "智信贷款平台是奇富借条下的一个子产品..."
文档2: "在智信平台有两类机构：机构绑卡扣款模式..."
文档3: "智信平台主要有以下系统：ice-crp路由系统..."
```

**Search Model的决策过程**:
```xml
<think>
用户询问智信平台的定义和功能。从检索结果看：
- 文档1直接说明了智信平台是奇富借条的子产品，并提到了连接用户和机构的功能
- 文档2和文档3提供了更多细节，但不是直接回答主要问题
- 文档1包含了回答问题所需的核心信息：平台定位、主要功能、商业模式
</think>

<search_complete>true</search_complete>

<important_info>
文档1
</important_info>
```

**结果**: Search Model判断一轮搜索就足够，选中文档1作为主要参考。

## 对比：复杂问题的多轮搜索

```xml

需要搜索更具体的状态转换规则。
```

## Search Model的关键能力

### 1. 信息完整性判断
- 评估当前信息是否足够回答问题
- 识别缺失的关键信息

### 2. 查询优化
- 根据已有信息生成更精确的搜索查询
- 使用领域特定术语（如"noticeRepayment"）

### 3. 相关性评估
- 从多个检索结果中选择最相关的文档
- 过滤掉虽然包含关键词但实际不相关的内容

### 4. 推理能力
- 理解问题的真实意图
- 识别需要多个信息源才能回答的复杂问题

## 为什么使用专门的Search Model？

1. **效率提升**: 避免不必要的搜索，简单问题一轮解决
2. **质量保证**: 复杂问题通过多轮搜索获取完整信息
3. **成本优化**: 搜索决策使用轻量级模型，生成使用重型模型
4. **可解释性**: 每个决策都有明确的推理过程

## 实际效果

从测试结果看：
- 21个问题中，20个（95%）一轮搜索解决
- 仅1个复杂推理问题需要3轮搜索
- 平均搜索时间仅5.89秒
- 100%的问题都得到了准确回答

这证明了Search Model在平衡效率和准确性方面的出色表现。
