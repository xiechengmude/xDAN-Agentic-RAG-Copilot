### 3.2 数据类型定义

```typescript
// 请求参数类型
interface CreateDatasetDto {
  name: string
  description?: string
}

interface UpdateDatasetDto {
  name?: string
  description?: string
}

interface ListDatasetParams {
  page?: number
  page_size?: number
  name?: string
}

interface ListDocumentParams {
  page?: number
  page_size?: number
  status?: DocumentStatus
}

// 响应数据类型
interface Dataset {
  id: string
  name: string
  description: string
  document_count: number
  created_at: string
  updated_at: string
}

interface Document {
  id: string
  name: string
  size: number
  status: DocumentStatus
  progress?: number
  created_at: string
  error_message?: string
}

enum DocumentStatus {
  UPLOADING = 'uploading',
  UPLOAD_FAILED = 'upload_failed',
  PARSING = 'parsing',
  PARSE_FAILED = 'parse_failed',
  PARSE_SUCCESS = 'parse_success'
}

// 基础响应类型
interface BaseResponse {
  code: number
  message: string
}

interface DataResponse<T> extends BaseResponse {
  data: T
}

interface PagedResponse<T> extends DataResponse<T[]> {
  total: number
  page: number
  page_size: number
}
```

## 四、接口调用流程示例

### 4.1 创建知识库并上传文件

```typescript
// 1. 创建知识库
const dataset = await datasetAPI.create({
  name: "产品文档库",
  description: "存储产品相关文档"
})

// 2. 上传文件
const files = [file1, file2, file3]
const uploadResult = await documentAPI.upload(dataset.id, files)

// 3. 监听文件状态
wsManager.subscribeFileStatus(dataset.id, (status) => {
  documentStore.updateDocumentStatus(status.doc_id, status.status, status.progress)
})

// 4. 触发文件解析
for (const doc of uploadResult.data) {
  await documentAPI.parse(dataset.id, doc.id)
}
```

### 4.2 基于知识库进行对话

```typescript
// 1. 选择知识库
chatStore.selectDataset(datasetId)

// 2. 创建对话会话
await chatStore.createChat(datasetId)

// 3. 发送消息
await chatStore.sendMessage("请介绍一下产品的主要功能")

// 4. 订阅流式响应
wsManager.subscribeChatStream(chatStore.currentChat.id, (message) => {
  // 更新UI显示流式内容
  updateChatUI(message.content)
})
```

## 五、错误处理规范

### 5.1 错误码定义

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 0 | 成功 | - |
| 400 | 请求参数错误 | 检查参数格式 |
| 401 | 未授权 | 跳转登录 |
| 403 | 无权限 | 提示无权限 |
| 404 | 资源不存在 | 提示资源不存在 |
| 409 | 资源冲突 | 如知识库名称重复 |
| 413 | 文件过大 | 提示文件大小限制 |
| 500 | 服务器错误 | 提示系统错误 |

### 5.2 错误处理示例

```typescript
try {
  await datasetAPI.create({ name: "测试知识库" })
} catch (error) {
  if (error.response?.status === 409) {
    message.error("知识库名称已存在")
  } else if (error.response?.status === 500) {
    message.error("服务器错误，请稍后重试")
  } else {
    message.error(error.message || "操作失败")
  }
}
```

## 六、性能优化建议

1. **分页加载**：知识库和文件列表采用分页加载，避免一次性加载过多数据
2. **防抖搜索**：搜索功能添加防抖，减少请求频率
3. **文件分片上传**：大文件采用分片上传，提高上传成功率
4. **状态缓存**：使用Vuex/Pinia缓存数据，减少重复请求
5. **WebSocket复用**：复用WebSocket连接，减少连接开销
6. **懒加载**：文件列表采用虚拟滚动或懒加载
7. **请求合并**：批量操作时合并请求，减少网络开销

## 七、安全考虑

1. **文件类型校验**：前后端都需要校验上传文件类型
2. **文件大小限制**：严格限制单文件和总文件大小
3. **XSS防护**：对用户输入进行转义处理
4. **CSRF防护**：使用Token防止CSRF攻击
5. **权限校验**：每个接口都需要进行权限校验
6. **敏感信息保护**：不在前端存储敏感信息
7. **HTTPS传输**：所有接口使用HTTPS加密传输
