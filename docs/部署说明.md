# xDAN Rag Copilot 部署说明

## 🚀 快速部署指南

### 🆕 最新特性：时间感知S3框架

xDAN Rag Copilot 现已集成时间感知功能到S3框架中，能够智能识别和处理时间相关的查询，提供更精准的搜索结果。

#### 核心功能
- **自动时间识别**：自动检测查询中的时间敏感关键词（如"最近"、"最新"、"近期"、"今年"等）
- **智能时间转换**：将相对时间词转换为具体的日期范围进行搜索优化
- **财报周期理解**：智能推断最新财报周期，考虑财报发布延迟
- **市场状态感知**：实时判断当前市场交易状态（交易时间、盘后时间、休市时间）

### 2. 本地开发


### 3. 远程部署

#### 3.1 后端部署

```bash

ssh user@150.109.16.195

# 克隆代码
git clone <repository-url>
cd ragflow-api-client

# 安装依赖
```

#### 3.2 前端部署

```bash
# 本地构建
cd frontend
npm run build

# 上传到服务器
scp -r dist/* user@150.109.16.195:/var/www/ragflow-client/

# 配置Nginx
sudo vim /etc/nginx/sites-available/ragflow-client
```

Nginx配置示例：
```nginx
server {
    listen 80;
    server_name 150.109.16.195;
    
    root /var/www/ragflow-client;
    index index.html;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API代理
    location /api {
        proxy_pass http://localhost:8001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

- **ENABLE_TIME_AWARE**: 启用/禁用时间感知功能（默认: true）

### 5. 服务管理

#### 使用systemd管理服务（推荐）

创建服务文件 `/etc/systemd/system/ragflow-api.service`:
```ini
[Unit]
Description=xDAN Rag Copilot API Service
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/home/your-user/ragflow-api-client
Environment="PATH=/home/your-user/ragflow-api-client/venv/bin"
ExecStart=/home/your-user/ragflow-api-client/venv/bin/python api_proxy.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable ragflow-api
sudo systemctl start ragflow-api
sudo systemctl status ragflow-api
```

### 10. 时间感知功能使用示例

#### 自动时间识别示例

1. **相对时间查询**
   ```
   输入："最近的财报数据"
   系统自动转换：搜索最近3个月的财报数据
   
   输入："今年的市场表现"
   系统自动转换：搜索2025年1月1日至今的数据
   ```

2. **财报周期智能推断**
   ```
   输入："最新季度财报"
   系统推断：
   - 当前时间：2025年7月
   - 最新可用财报：2025年Q2（考虑1-2个月发布延迟）
   - 搜索关键词：["2025年第二季度", "2025 Q2", "2025年二季报"]
   ```

3. **市场状态感知**
   ```json
   {
     "current_time": "2025-07-06 14:30:00",
     "market_status": "交易时间",
     "market_info": "A股市场正在交易中"
   }
   ```

#### API响应中的时间信息

当启用时间感知功能后，API响应会包含额外的时间上下文信息：

```json
{
  "code": 0,
  "message": "Success",
  "data": {
    "answer": "根据最新数据...",
    "reference": {
      "search_process": [
        {
          "round": 1,
          "query": "after:2025-04-06 最近的财报数据",
          "time_context": {
            "original_term": "最近",
            "converted_range": "2025-04-06 至 2025-07-06",
            "description": "最近3个月"
          }
        }
      ]
    },
    "time_context": {
      "query_time": "2025-07-06 14:30:00",
      "time_zone": "Asia/Shanghai",
      "market_status": "交易时间"
    }
  }
}
```

#### 配置时间感知搜索策略

在 `config.yaml` 中配置时间感知参数：

```yaml
s3_framework:
  time_aware:
    enabled: true
    # 相对时间词映射
    relative_terms:
      最近: 90    # 最近 = 90天
      最新: 30    # 最新 = 30天
      近期: 180   # 近期 = 180天
      今年: "ytd" # 今年 = 年初至今
    
    # 财报发布延迟（月）
    financial_report_delay: 2
    
    # 市场交易时间
    market_hours:
      open: "09:00"
      close: "15:00"
      timezone: "Asia/Shanghai"
```
