# xDAN Rag Copilot 部署说明

## 🚀 快速部署指南

### 1. 服务端口配置

#### 本地开发环境
- **前端开发服务**: http://localhost:5173
- **API代理服务**: http://localhost:8001
- **搜索演示服务**: http://localhost:8050

#### 远程生产环境 (150.109.16.195)
- **前端应用**: http://150.109.16.195 (通过Nginx)
- **API代理服务**: http://150.109.16.195:8001
- **RAGFlow原始服务**: http://150.109.16.195:7080
- **搜索演示服务**: http://150.109.16.195:8050

### 2. 本地开发

```bash
# 1. 启动API代理服务
source venv/bin/activate
python api_proxy.py

# 2. 启动前端开发服务
cd frontend
npm run dev
```

前端会自动代理 `/api` 请求到本地的 8001 端口。

### 3. 远程部署

#### 3.1 后端部署

```bash
# SSH到远程服务器
ssh user@150.109.16.195

# 克隆代码
git clone <repository-url>
cd ragflow-api-client

# 安装依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 启动API代理服务
nohup python api_proxy.py > api_proxy.log 2>&1 &

# 可选：启动搜索演示服务
nohup python demo_server_simple.py > demo_server.log 2>&1 &
```

#### 3.2 前端部署

```bash
# 本地构建
cd frontend
npm run build

# 上传到服务器
scp -r dist/* user@150.109.16.195:/var/www/ragflow-client/

# 配置Nginx
sudo vim /etc/nginx/sites-available/ragflow-client
```

Nginx配置示例：
```nginx
server {
    listen 80;
    server_name 150.109.16.195;
    
    root /var/www/ragflow-client;
    index index.html;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API代理
    location /api {
        proxy_pass http://localhost:8001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 5. 服务管理

#### 使用systemd管理服务（推荐）

创建服务文件 `/etc/systemd/system/ragflow-api.service`:
```ini
[Unit]
Description=xDAN Rag Copilot API Service
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/home/your-user/ragflow-api-client
Environment="PATH=/home/your-user/ragflow-api-client/venv/bin"
ExecStart=/home/your-user/ragflow-api-client/venv/bin/python api_proxy.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable ragflow-api
sudo systemctl start ragflow-api
sudo systemctl status ragflow-api
```

### 8. 常见问题

#### 端口被占用
```bash
# 查找占用端口的进程
lsof -i :8001
# 或
netstat -tlnp | grep 8001
```

#### 防火墙配置
```bash
# 开放必要端口
sudo ufw allow 80
sudo ufw allow 8001
sudo ufw allow 8050
```

#### 权限问题
确保用户有权限访问所需目录和端口。

### 9. 安全建议

1. **使用HTTPS**: 配置SSL证书
2. **限制API访问**: 使用防火墙规则限制8001端口的访问
3. **定期更新**: 保持系统和依赖包的更新
4. **日志监控**: 定期检查日志文件
