# DeepSearch统一Agent测试检查清单

## 概述
本清单用于验证统一Agent在接管Search-Select-Extract职责后，各个决策环节的功能完整性和质量标准。统一Agent负责从问题分析到内容提取的完整信息获取流程，专业生成模型(Gen LLM)负责最终报告输出。

---

## 1. 搜索策略规划 (Search Strategy Planning)

### ✅ 功能检查点
- [ ] **问题分解能力**
  - 复杂问题能分解为多个搜索维度
  - 识别主要信息需求和次要信息需求
  - 区分定量数据需求vs定性分析需求

- [ ] **渐进式搜索设计**
  - 第1轮：概览和背景了解
  - 第2轮：具体数据和详细分析
  - 第3轮+：验证、对比、缺口填补

- [ ] **搜索深度规划**
  - 根据问题类型调整深度（财务分析vs一般询问）
  - 平衡搜索广度和深度
  - 预测所需搜索轮数

### 🎯 质量标准
- 策略制定时间 < 30秒
- 搜索轮数预测准确率 > 80%
- 问题维度覆盖率 > 95%

### 🧪 测试用例
```
测试问题1: "分析特斯拉2024年在中国市场的表现"
预期策略: 财务数据 + 市场份额 + 竞争对手对比

测试问题2: "AI大模型在医疗领域的应用前景"
预期策略: 技术现状 + 应用案例 + 监管环境 + 市场预测
```

---

## 2. 查询生成优化 (Query Generation)

### ✅ 功能检查点
- [ ] **高级搜索操作符使用**
  - site: 用于官方源搜索
  - filetype: 用于特定文档类型
  - intitle: 用于标题精确匹配
  - 时间限定符 (after:, before:)
  - 布尔操作符 (AND, OR, NOT)

- [ ] **领域特定查询**
  - 财务: "quarterly report", "10-K filing", "earnings call"
  - 学术: site:arxiv.org, "peer reviewed", site:.edu
  - 市场: "industry report", "market analysis", filetype:pdf
  - 技术: "documentation", "API reference", "best practices"

- [ ] **查询进化策略**
  - 从宽泛关键词到精确专业术语
  - 根据前轮结果调整查询策略
  - 角度切换（历史趋势、竞争对手、监管等）

### 🎯 质量标准
- 查询生成时间 < 5秒
- 高级操作符使用率 > 60%
- 查询相关性评分 > 85%

### 🧪 测试用例
```
基础查询: "苹果公司财务报告"
优化查询: site:sec.gov "Apple Inc" 10-K 2024 filetype:pdf
预期改进: 精确度+90%, 权威性+95%
```

## 3. 信息源质量评估 (Source Quality Assessment)

### ✅ 功能检查点
- [ ] **权威性评分机制**
  - 官方报告: 10分 (SEC filings, 公司官网)
  - 学术论文: 9分 (ArXiv, 同行评议期刊)
  - 行业报告: 8分 (IDC, Gartner, McKinsey)
  - 主流媒体: 6分 (WSJ, Bloomberg, Reuters)
  - 专业博客: 3分 (个人专家分析)

- [ ] **内容质量判断**
  - 优先选择包含数据表格的来源
  - 识别图表和可视化内容
  - 评估具体数字和统计数据丰富度
  - 判断分析深度vs表面信息

- [ ] **时效性权衡**
  - 新信息 vs 权威性的智能平衡
  - 根据问题类型调整时效性权重
  - 历史数据 vs 最新趋势的选择

### 🎯 质量标准
- 权威性评分准确率 > 90%
- 高质量源选择率 > 80%
- 时效性权衡合理率 > 85%

### 🧪 测试用例
```
候选URL对比:
1. https://www.sec.gov/... (官方filing)
2. https://techcrunch.com/... (科技媒体)
3. https://blog.example.com/... (个人博客)

预期排序: 1 > 2 > 3
评分依据: 权威性 > 媒体可信度 > 个人观点
```

---

## 4. URL选择决策 (URL Selection Decision)

### ✅ 功能检查点
- [ ] **信息互补性分析**
  - 避免选择内容重复的URL
  - 追求不同类型信息源的组合
  - 平衡定量数据和定性分析

- [ ] **预期价值评估**
  - 预测每个URL能提供的信息类型
  - 评估与当前知识缺口的匹配度
  - 估算信息获取的投入产出比

- [ ] **选择数量控制**
  - 每轮选择1-3个最有价值的URL
  - 基于复杂度动态调整选择数量
  - 避免信息过载

### 🎯 质量标准
- URL选择准确率 > 85%
- 信息冗余率 < 20%
- 缺口覆盖率 > 80%

### 🧪 测试用例
```
场景: 需要苹果公司财务数据
12个候选URL中包含:
- 3个官方财报
- 4个新闻报道  
- 2个分析师报告
- 3个博客文章

预期选择: 1个官方财报 + 1个分析师报告 + 1个权威新闻
理由: 官方数据 + 专业分析 + 市场反应
```

## 5. 搜索完成判断 (Search Completion Assessment)

### ✅ 功能检查点
- [ ] **信息饱和度评估**
  - 核心问题组件覆盖率达80%以上
  - 多个权威源确认关键事实
  - 不同角度和视角的信息收集

- [ ] **质量充分性检查**
  - 定量数据充足性
  - 定性分析深度
  - 信息源权威性组合

- [ ] **边际收益递减识别**
  - 新搜索轮次带来的新信息比例
  - 重复信息出现频率
  - 搜索结果质量下降趋势

### 🎯 质量标准
- 完成判断准确率 > 90%
- 信息充足性评估准确率 > 85%
- 避免过度搜索率 > 80%

### 🧪 测试用例
```
财务分析问题完成标准:
✅ 收入数据: 季度+年度
✅ 利润指标: 毛利率+净利率  
✅ 市场地位: 份额+排名
✅ 竞争对比: 主要对手数据
✅ 趋势分析: 同比+环比

当满足4/5标准时判断搜索完成
```

## 5. 内容理解和提取 (Content Understanding & Extraction)

### ✅ 功能检查点
- [ ] **结构化内容提取**
  - 准确提取核心信息回答问题
  - 识别和保留重要数据、统计、事实
  - 提取关键观点和专家分析
  - 保留背景信息和上下文

- [ ] **内容质量评估**
  - 评估提取内容的准确性和完整性
  - 识别信息的权威性和可信度
  - 考虑信息的时效性和相关性
  - 确保内容结构化便于后续生成

- [ ] **智能内容整理**
  - 按重要性排序提取的信息
  - 去除冗余和低价值内容
  - 为生成模型准备高质量结构化内容
  - 标识仍需补充的信息类型

### 🎯 质量标准
- 内容提取准确率 > 95%
- 关键信息覆盖率 > 90%
- 结构化程度评分 > 85%
- 为生成模型的可用性 > 90%

### 🧪 测试用例
```
原始网页: 苹果公司财报网页(5000字)
预期提取结构:
## 核心信息: 收入、利润、增长率
## 重要数据: 具体财务数字、同比变化
## 关键观点: 管理层展望、分析师评价
## 背景信息: 行业环境、竞争状况
## 时效要点: 最新季度表现、未来指引

质量要求: 提取1500字左右，保留核心价值
```

## 6. 缺口分析与迭代 (Gap Analysis & Iteration)

### ✅ 功能检查点
- [ ] **具体缺口识别**
  - 精确识别缺失的信息类型
  - 量化缺口的重要性程度
  - 评估缺口填补的可行性

- [ ] **针对性查询生成**
  - 基于缺口分析生成精准查询
  - 调整搜索角度和策略
  - 尝试不同的信息源类型

- [ ] **搜索角度创新**
  - 竞争对手视角
  - 历史趋势对比
  - 监管环境分析
  - 用户/客户反馈角度

### 🎯 质量标准
- 缺口识别准确率 > 90%
- 针对性查询有效率 > 80%
- 角度创新成功率 > 70%

### 🧪 测试用例
```
已获取信息: 苹果Q4财报数据
识别缺口: 竞争对手同期数据
生成查询: "Samsung Q4 2024 smartphone revenue" OR "Google Pixel Q4 sales"
预期结果: 获得对比基准数据
```
