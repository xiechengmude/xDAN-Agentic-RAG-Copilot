## 概述

FlashSearch v2.1.0 是基于KISS和DRY原则设计的简化搜索引擎，借鉴了原DeepSearch架构的优点，在保持简洁性的同时提供可靠的搜索体验。

## 核心特性

### ✅ 借鉴原架构优点
1. **URL修复和过滤**: 处理BrightData返回的问题URL
2. **摘要回退机制**: 爬取失败时使用snippet保证成功率
3. **时间感知处理**: 为无时间上下文的问题添加年份
4. **引用标注区分**: 区分完整内容和摘要内容的来源

### ✅ 遵循KISS+DRY原则
1. **移除复杂组件**: 无Agent决策、无多轮搜索、无复杂配置
2. **硬编码参数**: 避免运行时配置开销
3. **单一职责**: 每个方法专注一个功能
4. **最小依赖**: 只依赖必要的基础客户端

## 详细流程

### 1. 时间感知处理
```python
def _enhance_question_with_time(self, question: str) -> str:
    time_keywords = ['最新', '最近', '今年', '2024', '2025', '当前', '现在']
    has_time_context = any(keyword in question for keyword in time_keywords)
    
    if not has_time_context:
        current_year = datetime.now().year
        return f"{question} {current_year}"
    return question
```

### 3. 摘要回退机制
```python
# 爬取失败时
if content and content.get("content"):
    return {"url": url, "content": content["content"], "is_fallback": False}
else:
    # 回退到snippet
    return {"url": url, "content": f"摘要信息: {snippet}", "is_fallback": True}
```

### 4. 引用标注增强
```python
def _format_source_citation(self, content_item: Dict, index: int) -> str:
    title = content_item.get("title", f"来源{index}")
    is_fallback = content_item.get("is_fallback", False)
    
    if is_fallback:
        return f"【来源{index}-摘要】{title}"
    else:
        return f"【来源{index}】{title}"
```
