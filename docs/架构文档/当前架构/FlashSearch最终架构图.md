## 概述

FlashSearch v2.5.0 是基于KISS和DRY原则设计的简化搜索引擎，在v2.4.0新闻领域增强的基础上，新增了Google关键词优化和时间感知搜索算子，显著提升搜索精度和结果数量。通过简化核心目录结构，移除冗余代码，进一步优化了架构的简洁性和可维护性。

## 核心特性

### ✅ 借鉴原架构优点
1. **URL修复和过滤**: 处理BrightData返回的问题URL
2. **摘要回退机制**: 爬取失败时使用snippet保证成功率
3. **智能搜索策略**: 领域识别、关键词增强、搜索算子优化
4. **引用标注区分**: 区分完整内容和摘要内容的来源

### ✅ 遵循KISS+DRY原则
1. **模块化设计**: 搜索策略独立模块，易于维护和扩展
2. **硬编码参数**: 避免运行时配置开销
3. **单一职责**: 每个方法专注一个功能
4. **最小依赖**: 只依赖必要的基础客户端
5. **代码简化**: 移除冗余文件，保持核心目录清洁

### 🆕 v2.5.0 新增特性
1. **Google关键词优化**: 提取3-8个核心关键词，搜索结果数量提升128%
2. **时间感知算子**: 深度理解相对时间词，自动转换为精确搜索算子
3. **代码架构简化**: 移除flash_s3.py冗余文件，统一使用flash_s3_enhanced.py
4. **保持v2.4.0特性**: 
   - 新闻领域增强
   - 权威媒体集成
   - 选择重试机制
   - 搜索策略模块化

## 详细流程

### 1. 搜索策略优化流程
```python
# 完整的搜索优化流程（v2.5.0增强版）
result = search_strategy.optimize_search_query(question)

# 步骤1: 问题分析
analysis = search_strategy.analyze_question(question)
# 返回: 领域检测、问题类型、复杂度评估

# 步骤2: 时间感知增强（新增相对时间解析）
time_enhanced = search_strategy.enhance_with_time_context(question, analysis)
# "最近比亚迪财报" → "比亚迪财报 2025 after:2024-10-01"

# 步骤3: Google关键词优化（v2.5.0新增）
google_optimized = search_strategy.optimize_for_google(time_enhanced, analysis)
# "比亚迪财报 2025" → "比亚迪 财报 2025 年报 BYD financial report"

# 步骤4: 搜索算子优化
final_query = search_strategy.add_search_operators(google_optimized, analysis)
# "比亚迪 财报 2025 年报" → "after:2024 filetype:pdf 比亚迪 财报 2025 年报"
```

### 3. 摘要回退机制
```python
# 爬取失败时
if content and content.get("content"):
    return {"url": url, "content": content["content"], "is_fallback": False}
else:
    # 回退到snippet
    return {"url": url, "content": f"摘要信息: {snippet}", "is_fallback": True}
```

### 4. 引用标注增强
```python
def _format_source_citation(self, content_item: Dict, index: int) -> str:
    title = content_item.get("title", f"来源{index}")
    is_fallback = content_item.get("is_fallback", False)
    
    if is_fallback:
        return f"【来源{index}-摘要】{title}"
    else:
        return f"【来源{index}】{title}"
```
