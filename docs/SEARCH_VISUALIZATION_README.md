# 智能体搜索过程可视化

## 功能概述

本功能将S3（Search-Select-Synthesize）框架中的智能体搜索过程完全透明化，让用户能够实时看到：

- 🔍 **搜索轮次**: 智能体进行了多少轮搜索
- 💭 **思考过程**: Search Model的推理和决策过程
- 📝 **查询演化**: 如何优化搜索查询以找到更相关的信息
- 📚 **文档选择**: 从大量文档中如何筛选出最相关的内容
- ✨ **答案生成**: 基于选中文档如何生成最终答案

## 核心组件

### 1. 增强版S3服务 (`enhanced_s3_rag_service_v2.py`)
- 支持事件回调机制
- 详细记录每个搜索步骤
- 保留完整的决策历史

### 2. 搜索过程API (`search_process_api.py`)
- RESTful API端点
- Server-Sent Events (SSE) 支持
- WebSocket实时通信
- 完整的事件类型系统

### 3. 前端可视化组件
- 原生HTML/JS示例
- React组件示例
- 实时更新的时间线视图
- 交互式事件详情展示

## API使用

### 1. SSE流式接口

```javascript
const eventSource = new EventSource('/api/v2/search/stream?question=你的问题');

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(`事件类型: ${data.event_type}`);
  console.log(`事件数据:`, data.data);
};
```

### 2. WebSocket接口

```javascript
const ws = new WebSocket('ws://localhost:8000/ws/search/client123');

ws.send(JSON.stringify({
  action: 'search',
  params: {
    question: '你的问题',
    max_rounds: 3
  }
}));
```

### 3. 完整结果接口

```bash
curl -X POST http://localhost:8000/api/v2/search/complete \
  -H "Content-Type: application/json" \
  -d '{"question": "什么是智信平台？"}'
```

## 事件类型说明

| 事件 | 含义 | 关键数据 |
|------|------|----------|
| `search_start` | 搜索开始 | 问题、配置 |
| `documents_retrieved` | 文档检索完成 | 文档数、相似度 |
| `agent_thinking` | 智能体思考中 | 思考状态 |
| `agent_decision` | 智能体决策 | 推理过程、决策结果 |
| `new_query_generated` | 生成新查询 | 新查询内容 |
| `search_complete` | 搜索完成 | 总轮数、耗时 |
| `answer_generated` | 答案生成 | 最终答案 |

## 前端集成建议

1. **实时更新**: 使用SSE或WebSocket获取实时事件
2. **视觉反馈**: 不同事件类型使用不同颜色/图标
3. **交互设计**: 点击事件查看详情
4. **性能优化**: 大量事件时使用虚拟滚动
5. **用户体验**: 提供搜索进度和预计剩余时间

通过将智能体的搜索过程完全透明化，我们不仅提升了用户体验，还为系统优化提供了重要的洞察。这种可视化方案展示了现代AI系统如何通过多轮迭代搜索和智能决策来提供高质量的答案。
