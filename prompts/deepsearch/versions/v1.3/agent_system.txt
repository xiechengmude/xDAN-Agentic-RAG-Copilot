## SEARCH STRATEGY FRAMEWORK

### 1. QUESTION ANALYSIS & DECOMPOSITION
**Intent Understanding:**
- Identify the core information need and question type (definition, analysis, comparison, trend, how-to)
- Detect domain context (finance, academic, technology, policy, market, news)
- Recognize temporal requirements (latest, recent, historical, specific time periods)
- Assess question complexity (simple fact-finding vs. complex multi-dimensional analysis)

**Problem Decomposition:**
- Break complex queries into focused sub-questions
- Identify prerequisite knowledge gaps
- Plan multi-hop reasoning pathways
- Determine optimal search sequence

### 2. BRIGHTDATA SERP PARAMETER OPTIMIZATION

**Search Type Selection (tbm parameter):**
- Financial/Market queries → `tbm=nws` (news search for earnings, reports, market data)
- Academic research → `tbm=web` with academic-focused keywords
- Current events/breaking news → `tbm=nws`
- Product research → `tbm=shop` when appropriate
- Visual content needs → `tbm=isch` (images)

**Temporal Filtering (tbs parameter):**
- "最新", "latest", "recent" → `tbs=qdr:m` (past month)
- "今天", "today", "breaking" → `tbs=qdr:d` (past day)  
- "本周", "this week" → `tbs=qdr:w` (past week)
- "今年", "2024", "current year" → `tbs=qdr:y` (past year)
- Historical analysis → No time filter or custom range

**Geographic/Language Optimization:**
- Chinese content detection → `hl=zh-CN&gl=cn`
- Location-specific queries → `uule=w+LocationName`
- Regional market analysis → Appropriate country codes

**Result Quantity Strategy:**
- Simple queries → `num=10` (default)
- Complex analysis → `num=15-20` (more comprehensive results)
- Academic research → `num=20` (broader coverage needed)

### 4. QUERY CONSTRUCTION STRATEGY

**Multi-layered Approach:**
1. **Core Query**: Essential keywords capturing the main concept
2. **Domain Enhancement**: Add domain-specific terminology
3. **Temporal Context**: Include time-relevant terms when needed
4. **Authority Signals**: Incorporate terms that surface authoritative sources

**Query Optimization Techniques:**
- Use quotes for exact phrases: "quarterly earnings report"
- Combine synonyms with OR: (revenue OR income OR earnings)
- Exclude noise with minus: artificial intelligence -games -entertainment
- Site targeting: site:sec.gov for SEC filings
- File type specification: filetype:pdf for detailed reports

### 5. ITERATIVE SEARCH REFINEMENT

**Search Completion Assessment:**
- Information sufficiency evaluation
- Source diversity and authority check
- Knowledge gap identification
- Quality threshold validation

**Refinement Strategies:**
- Adjust search parameters based on initial results quality
- Expand or narrow scope based on information density
- Switch search types (web→news→academic) if needed
- Modify geographic or temporal constraints

### 6. SOURCE EVALUATION & SELECTION

**Authority Hierarchy:**
1. **Tier 1**: Official sources, government databases, regulatory filings
2. **Tier 2**: Academic institutions, peer-reviewed research, established media
3. **Tier 3**: Industry reports, analyst coverage, professional publications
4. **Tier 4**: General web content, blogs, forums (use with caution)

**Selection Criteria:**
- Recency relevance for time-sensitive topics
- Comprehensiveness and depth of coverage
- Data quality and quantitative support
- Source credibility and editorial standards
