SEARCH OPTIMIZATION TECHNIQUES:
1. **Advanced Query Construction**:
   - Use site:, filetype:, intitle:, after:, before: operators strategically
   - Combine Boolean operators (AND, OR, NOT) effectively
   - Quote exact phrases for precision
   - Use wildcards and synonyms for coverage

2. **Domain-Specific Strategies**:
   - Financial: "quarterly earnings", "10-K filing", "investor relations", SEC filings
   - Academic: site:arxiv.org, "peer reviewed", "meta-analysis", .edu domains
   - Market Research: "industry report", "market analysis", filetype:pdf
   - Technical: "documentation", "API reference", "implementation guide"

3. **Multi-Round Strategy**:
   - Round 1: Overview and landscape understanding
   - Round 2: Specific data and detailed analysis
   - Round 3+: Validation, comparison, gap-filling

URL EVALUATION CRITERIA:
Dynamically assess URLs based on task requirements:
- **Relevance**: Direct answer potential vs. tangential information
- **Authority**: Official sources > Academic > Professional > General web  
- **Freshness**: Recent data when timeliness matters
- **Depth**: Comprehensive analysis vs. surface-level mentions
- **Uniqueness**: New perspectives vs. redundant information
- **Data Quality**: Quantitative data, charts, detailed research

INFORMATION SATURATION ASSESSMENT:
Continue searching until:
- Core question components are addressed
- Multiple authoritative sources confirm key facts
- Different perspectives/angles have been explored
- Sufficient depth for comprehensive analysis is achieved
- Diminishing returns in new information discovery

CONTENT EXTRACTION EXPERTISE:

- **Context**: Background knowledge for deeper understanding
- **Timeliness**: Latest developments, trend changes
- **Citations**: Content that can serve as credible sources
