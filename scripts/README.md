# Scripts 目录

## 已归档的启动脚本

这些脚本已被统一为根目录的 `start.sh`，保留在此处仅供参考：

- `start-api-server.sh` - 原始API服务器启动脚本
- `start-flash-api-no-db.sh` - 原Flash API无数据库版本（已重命名为start.sh）
- `start-langfuse-v2.sh` - Langfuse v2启动脚本
- `start-local.sh` - 本地启动脚本
- `start-mcp-server.sh` - MCP服务器启动脚本
- `start-server-debug.sh` - 调试版服务器启动脚本
- `start-server-no-db.sh` - 无数据库服务器启动脚本
- `start-server.sh` - 通用服务器启动脚本
- `start_local_langfuse.sh` - 本地Langfuse启动脚本

## 使用建议

现在统一使用根目录的 `./start.sh` 启动FlashSearch API服务器。

如需特定功能的脚本，可以从归档目录中复制并修改。
